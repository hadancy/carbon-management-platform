# 阶段 3 默认业务决策与权限

本记录采用 2026-09-23 阶段 3 开发时用户认可的建议方案。后续如有业务调整，应修改此记录、权限代码和测试。

## 账号与学校

- 一个用户可以加入多所学校。每次学校业务请求使用当前学校，并在服务端重新验证该校成员关系和学校状态。
- 平台超级管理员独立于学校成员身份。平台角色只授权学校、账号及公共数据管理；没有学校成员关系时，不能访问学校私有业务。
- 首期由平台超级管理员统一创建学校和账号，并为每所学校创建至少一位学校管理员。学校管理员暂不管理账号。
- 账号由平台管理员设置初始密码；用户登录后可自行更改。无邮件发送服务时，忘记密码由平台管理员重置。
- “学校与账号”工作区支持按学校维护成员和跨校查询账号。平台管理员可删除非平台管理员账号；删除会撤销会话与登录凭据、移除全部学校归属，并保留匿名历史记录供审计和公共数据引用。平台管理员账号不可删除。
- 平台管理员不能通过认证插件代入学校用户身份。认证插件管理端点仅在服务器内部由本项目受保护的接口调用。

所有校内角色均可读取本校有权限展示的数据。模型、核算与报告审核 API 校验当前状态，禁止创建人、最后编辑人或提交人自审；学校管理员同样受限。报告编辑包含创建、草稿保存和新修订；报告导出只对已通过审核的修订开放，历史通过版本可继续下载。预览、生成与下载均重新校验学校身份和角色，平台权限不代替校内权限。

## 公共数据范围

首期公共数据类型为公共排放因子、标准与公式配置、通用报告模板。平台管理员创建草稿、填写版本和来源、发布；学校用户只读已发布版本。发布后版本内容冻结，变更需创建新版本。公用排放因子草稿用数值与受控活动数据单位录入，发布前校验二者完整性，分子统一按 `kgCO₂e` 记录；旧版自由 JSON 因子须人工核对后才能转换为新结构。正式核算已读取发布因子 v2 与规则配置，并校验用途、期间、范围和受控公式代码。公共报告模板仍作为资料维护；T07 使用版本化内置工程模板，业务模板通过受控映射接入，任意 JSON 不作为脚本或 HTML 执行。

## 已实现的业务规则与后续扩展

- 公用模型模板由平台管理员维护和发布；学校只读取已发布的公用版本，引用时复制为本校草稿并记录来源版本。平台管理员不因此获得学校私有模型的查看或审核权限。
- 本校用户自行添加阶段、大类和数据项；拥有模型编辑权限的角色提交版本，拥有模型发布权限的校内角色审核、驳回或发布。创建人、最后编辑人和提交人不得审核同一版本。
- 已发布模型版本不原位编辑，新修改形成新版本；公用模板更新不自动更改学校版本。
- 已审核核算和报告固定快照，重算或改写产生新修订；报告说明与数值分离，提交即冻结说明，原审核意见和 PDF 保留。详见 [T07 验收记录](T07报告验收记录.md)。
- 首期先支持光伏闭环和 PDF 报告，光热、风电与 Word 导出后续接入。
