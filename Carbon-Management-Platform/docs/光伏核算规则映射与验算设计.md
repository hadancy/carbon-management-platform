### 2.1 来源与因子选择

表 1～4 对因子来源给出优先序：上游供应商数据、政府发布数据、行业数据、经第三方评估的数据库、文献、附录参考值等。设计上先筛选**产品/设备、单位、地域、技术、适用年份和授权范围**，再记录采用理由及来源优先级；不得因为某条因子排在前面就忽略适用性。第 7.2.5 条对全国输配电因子和线损率要求采用政府部门、行业协会公布的最新数据；表 5 规定电量数据收集要求。附录 A 表 A.4、A.6 带年度值，更新时新增版本，不改写旧运行引用。

**工程选择：首版沿用 `PublicDataVersion`，以 `type=EMISSION_FACTOR` 的记录 ID 作为 `factorVersionId`，每条版本记录代表一个因子。** 增强其 `content` 结构校验，避免同时维护两套公共因子主数据。未来确需学校私有因子或独立索引查询时，再设计带数据迁移方案的专表。

| 字段组     | 必要内容                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 身份与数值 | 因子编码、版本、状态、十进制数值、`kgCO2e` 分子单位、活动数据分母单位                                                                   |
| 适用性     | 产品/设备或运输方式、地域、技术、适用起止日期、数据所属年度、适用阶段及排放边界                                                         |
| 证据       | 来源类别、文件/机构、表号或页码、发布时间、原始数值与换算过程、授权说明                                                                 |
| 治理       | `schemaVersion`、用途 `TEST/PRODUCTION`、创建与发布人、业务依据引用、发布时间、停用时间、替代版本和变更原因；首版沿用平台管理员发布流程 |

模型数据项声明因子类型、分母单位和阶段归属，案例修订显式选择因子版本，运行再固定全部引用和数值快照。现有因子已有数值、活动单位和发布来源检查，但不含完整的适用性校验。新增内容结构按 `schemaVersion=2` 识别，旧记录不就地修改：保留阅读能力，从旧版本复制草稿、补齐来源和适用性后发布新版本。

选择因子时展示数据年度、地域、边界和来源，不自动用“最新”覆盖选择。跨年度活动拆成分段输入；不能覆盖目标年度的因子须补充明确的外推依据。资料所属年、发布时间、适用期是不同字段，`2024 年度因子`不等于只能在 2024 年发布或使用。候选值能否用于未来估算年属于案例方法说明。

因子停用作为独立元数据变更记录审计，不删除被引用版本、不修改其内容。新计算禁止选择停用版本；历史运行仍可读取和复现。后来发现因子错误时给受影响运行标记复核提示，修订案例后重算，不回写旧值。测试用途记录不能参与正式提交，转为生产用途须发布有依据的新版本。

### 2.2 单位、数值及缺失值规则

- 单位目录需补齐光伏标准使用的 `kW`、块、套、辆以及换算用 `Wh` 等单位；当前目录已有 `t`、`kg`、`m`、`m3`、`kWh`、`km` 和 `t·km` 等，但“有目录项”不等于“已定义换算”。
- 每次计算先统一活动数据与因子分母单位，记录原值、原单位、目标单位和换算系数。首版自动换算覆盖 g/kg/t、Wh/kWh/MWh、m/km、L/m³ 等有确定关系的单位；功率 kW 与电量 kWh 不可直接转换，块/台等数量单位不能彼此互换。块↔kW、L↔kg 等须增加额定功率、密度等专用参数及证据，首版不自动处理。
- 运输输入为重量和距离，因子分母固定为 `t·km`，不能把重量单位自动拼成 `kgCO2e/t`。其他因子同样校验实际分母，不能通过改变显示标签来改变因子含义。
- 活动数量、距离、电量应为有限的非负十进制数；分母按场景校验，见第 2.3 节。界面接收百分数，入引擎统一换为比例：`0 ≤ η < 1`、`0 < PR ≤ 1`、`0 ≤ deg < 1`；不可重复除以 100。负因子或回收抵扣首版返回不支持原因。
- 缺失不等于零。草稿可保存缺项；计算、提交和审核时列出缺项并阻断。若某阶段经确认不适用，应保存“不适用”的理由，不能用空值隐式当 0。
- 运算采用十进制库，暂定 50 位有效数字；JSON 中数值按十进制字符串传递并存储，禁止先经 JS `Number` 丢失精度。输入建议限 18 位整数和 18 位小数，超限明确报错；精度和范围均作为工程配置版本保存，不宣称是标准规定。
- 试算展示约定：排放量/电量 2 位小数，`CFP_pv` 6 位小数，`ROUND_HALF_UP`；小于显示精度的正数以“小于最小显示值”提示。运算与快照保留运算精度，表格展示值不回流计算；正式报告口径由 B05 确认，变化须形成新规则配置版本。

### 2.3 供电场景与年度电量

令 `E4 = Em_rs + Em_tr + Em_cs + Em_us`。场景是案例的必填选择，不能仅根据某个字段为零推断。

| 场景                 | 必要输入及计算                                                                       | 首版启用策略                                                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `GRID_ONLY` 并网     | `E_oge>0`、`E_dps=0`、`0≤η<1`；`CFP=(E4+Em_td)/(E_oge×(1−η))`，与公式 (1) 此情形等价 | 先实现；简化法中 `Em_td` 必须使用同一份生命周期 `E_oge`，禁止另填一份不一致的电量。                                                             |
| `DIRECT_ONLY` 纯直供 | `E_oge=0`、`E_dps>0`、`η=0`、`Em_td=0`；候选分支为 `CFP=E4/E_dps`，跳过输配电分式    | 这是结合标准直供条件得到的工程解释，须 B02 确认后启用。首版保存草稿时允许 `E_oge=0`；计算入口返回“纯直供尚未启用”，不能报“所有电量必须大于零”。 |
| `MIXED` 混合         | `E_oge>0`、`E_dps>0`，按公式 (1)；第一项与第二项的分母不同                           | B02 确认统计边界和分配口径后扩展；报告分阶段强度按各自公式贡献输出，不能把所有阶段除以同一分母。                                                |

年度电量清单记录 `operatingYear=1…N`、对应日历期间、`ACTUAL/ESTIMATED`、电量、证据和参数。运行年数 `N` 必须为正整数；25～30 年是标准中的参考范围，超范围须有设计依据；估算指数使用投产以来的运行年序号，不从“剩余第 1 年”重新起算。每个运行年只出现一次，实际值替代该年的估算值；输入年份缺口、重叠或生命周期未覆盖会阻断完整计算。

- 固定衰减率候选实现：`E_y=W×H×PR×(1−deg)^y`，只对缺少实际值的年份应用；不把实际年度数据再加进同一年的估算值。
- 分年衰减候选实现：`E_y=W×H×PR×∏(1−deg_k), k=1…y`。采用首年 3%、其后 0.45% 的参考办法时，首年系数仅用一次，不用恒定 0.5% 替代。
- 若输入已经是含衰减的首年设计上网电量，不能再乘一次首年衰减或系统能效。记录基准量含义和估算方法，具体换算由 B03 确认。
- 采集期间与生命周期是独立概念。未来年份的因子、维护量和电量估算需记录假设及适用依据；设计寿命本身不意味着缺失年度可以按零填充。
- 首版以完整运行年度作为自动汇总单元；首尾不足一年或跨日历年数据须说明与运行年度的对应关系。部分年度实测不能直接替代整年估算，未完成期间分段/折算方法确认时提示补齐年度清单。

同一组件已使用包含上游生产的完整产品碳足迹因子时，其覆盖的硅料、硅片、电池片排放不能再作为额外排放重复叠加。因子边界和活动覆盖范围须进入复核，不能仅凭数据行 ID 不同就视为独立活动。舍弃项需保存影响占比所用的统一分母、估算及证据，缺少估算时不能仅勾选“低于 1%”。

## 3. 运行、审核与报告数据流

```text
已发布学校模型版本 + 已发布且适用的因子版本 + 有证据的活动数据
  → 单位与适用性校验 → 逐项/逐阶段计算 → 总上网电量和 CFP_pv
  → 新建不可变 CalculationRun（规则、输入、因子、过程、结果快照）
  → 校内有审核权限且非创建/最后编辑/提交人的用户审核指定运行
  → 报告引用该运行并生成修订版
```

工程试算可直接使用已发布模型数据项内填写的数值因子，并将其标为 `TEST` 固定到快照；正式计算必须改用经确认的公用因子 v2 和规则版本。模型内因子目前没有独立的地区、期间和授权字段，不能以试算结果替代正式资格校验。

- 每次重算生成新的运行 ID；模型、因子或活动数据后续变化不改写旧运行。审核结果绑定运行 ID，报告绑定已审核运行 ID。
- 服务端依据当前学校解析并校验 `schoolId`，关联的模型、案例、附件和私有因子不得跨校；平台管理员的公共数据权限不自动授予学校私有核算读取权限。
- 记录计算规则集版本、标准引用、每条规则 ID、单位转换、因子来源及数值、输入证据 ID、分阶段结果、最终结果、警告、操作者和时间。旧运行按其快照复现，不重新读取当前因子库。
- 发布因子、重算、审核、报告导出写入审计；导出 PDF 从同一运行及报告修订快照生成。

`inputHash` 由服务端对规范化输入、引用版本和证据内容摘要计算，固定对象键序和十进制表示；不信任客户端上送摘要。引擎实现版本及对应构建产物保留到历史运行保存期结束，否则只能查看快照，不能宣称能执行旧算法重现。

### 3.2 状态流转和接口行为

1. **草稿与计算**：草稿允许缺项；完整计算要求覆盖五阶段和电量，错误返回字段路径、规则 ID、错误码与修改提示。只计算完整的单阶段可作为预览，但必须标记未完成，不能提交完整案例。
2. **输入变化**：保存草稿须携带 `expectedInputRevision`。版本不符返回冲突，禁止覆盖他人编辑。已生成的运行继续保留；输入修改后旧运行标为“对应较早输入”，需要重算才能提交。
3. **提交与审核**：一次事务确认当前 `inputRevision`、运行 `inputHash`、因子/规则资格、证据和权限后，锁定该修订。审核只接受 `SUBMITTED`；批准或驳回均保存意见与操作者。创建人、最后编辑人和提交人不能审核，学校管理员也受此限制。
4. **驳回与修订**：驳回或已批准后修改，复制成新草稿修订；原输入、运行和审核记录保留。已批准的旧修订不会被新草稿替代为未审核状态，报告继续引用原已批准版本。
5. **重复请求**：相同 `requestId`、相同输入返回同一运行；相同 `requestId`、不同输入返回冲突。用户主动重算使用新请求 ID，生成新运行；失败计算不产生可提交的成功记录。事务和唯一约束防止连点造成重复提交/审核。
6. **跨校校验**：数据库读取及写入均约束当前学校，验证修订、模型版本、证据和运行的关联归属；公共因子只放行类型、用途和适用性均符合的已发布版本。无权限时不泄露其他学校记录是否存在。

## 4. 现有原型数据的验算与差异

以下仅用于发现工程问题，**不是业务签认样例，也不能作生产默认数据**。原型 `TRAIN_ACC_SEED` 有一例：前四阶段排放量分别为 `152290`、`2500`、`7390`、`29050 kgCO2e`；`E_oge = 23500644.79 kWh`；输配电阶段存为 `1680 kgCO2e`；`η = 5%`，`E_dps = 0`。这些数值及来源尚未核验。

| 检查点         | 原型当前数据/行为                                                                            | 标准映射后的处理                                                                                                                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 输配电因子     | 原型上网与“自供电量”行均使用 `0.0014 kgCO2e/kWh`，按 `1000000 + 200000 kWh` 得 `1680 kgCO2e` | 附录 A 表 A.6 给出的示例为 **2023 年 0.0036、2024 年 0.0046 kgCO2e/kWh**，且提示按政府发布值更新。先确认年份和简化法条件；公式 (6) 的电量基数是 `E_oge`，直供电产品因子取 0。不得直接继承原型的 `1680`。 |
| 电量与寿命     | 原型把 `2024` 年实际 `1000000 kWh` 与 `RSL=25` 年估算项相加，得到 `23500644.79 kWh`          | 标准注释要求估算年从实际发生年的下一年至设计运行年末。须明确投产年、实际年和剩余估算年份，避免 25 年设计寿命算成 26 年。                                                                                 |
| 因子与模型联动 | 原型打开已选核算行时可从模型同步因子并重算排放                                               | 核算运行固定模型及因子快照；模型新版本只影响后续运行。                                                                                                                                                   |
| 数值处理       | 原型使用 `parseFloat`、JS 浮点运算及每行 `toFixed(2)`                                        | 服务端严格解析、校验单位、用十进制运算；舍入节点由已确认规则规定。                                                                                                                                       |
| 报告           | 原型根据当前核算对象生成文字和表格                                                           | 从指定已审核运行与报告修订快照生成，保持历史报告数值稳定。                                                                                                                                               |

若仅为**演示差异**，把原型 `E_oge` 与附录 A 表 A.6 的 2024 年值 `0.0046` 相乘，简化法的 `Em_td` 约为 `108102.97 kgCO2e`，明显不同于原型 `1680 kgCO2e`。这个乘积不能替代适用年份、数据来源及简化法条件的业务核实。

## 5. 工程验证与业务验收

### 5.1 可立即使用的工程样例

**SYN-PV-001 是人工构造的算术测试，不代表真实电站。** 其中 `0.0046` 仅引用 PDF 附录 A 表 A.6 的 2024 年资料值演示公式，其余因子和活动数据均为测试假设。测试标记覆盖整个案例；任何一条数值来自标准附录，都不能使该案例成为业务验收样例。
